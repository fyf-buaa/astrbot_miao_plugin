

# AstrBot Miao Plugin

原神/星穹铁道多功能查询插件

## 介绍

AstrBot Miao Plugin 是一个为 [AstrBot](https://github.com/AstronIsm/astrbot) 框架开发的游戏查询插件，支持米哈游旗下游戏的角色数据查询、面板管理、WIKI 查询等功能。目前支持《原神》和《崩坏：星穹铁道》两款游戏。

## 功能特性

| 功能 | 说明 |
|------|------|
| **面板查询** | 查看游戏角色详细养成数据 |
| **角色卡片** | 生成精美的角色展示图片 |
| **WIKI 查询** | 角色技能、天赋、材料等信息 |
| **伤害计算** | 计算角色伤害输出能力 |
| **排行榜** | 群聊内角色数据排行 |
| **日历** | 游戏内活动/角色生日日历 |
| **材料追踪** | 今日副本/突破材料提示 |

## 支持的游戏

- `gs` - 原神 (Genshin Impact)
- `sr` - 崩坏：星穹铁道 (Honkai: Star Rail)

## 安装依赖

```bash
pip install -r requirements.txt
```

## 配置说明

插件配置项在 `_conf_schema.json` 中定义，主要配置包括：

- API 服务配置 (Enka API / Mihomo API)
- 渲染样式配置
- 管理员设置
- 功能开关

首次使用需通过机器人管理员命令进行基本配置。
